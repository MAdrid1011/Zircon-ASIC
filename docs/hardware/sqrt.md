# 平方根 sqrt

`FpSqrt` 计算同格式的 $\sqrt{x}$，支持 FP32、FP16、BF16 和五种舍入方式。Python 提供 `FpSqrt`、`FP32Sqrt`、`FP16Sqrt`、`BF16Sqrt`，Chisel 通过 `Arithmetic(format, "sqrt")` 实例化。

## 被开方数与指数

解码逻辑将有限正数的指数奇偶并入有效数，表示为 $x=m'2^{2q}$，其中 $1\le m'<4$。输出有效数为 $\sqrt{m'}$，指数为 `q`。次正规输入先规格化，再使用相同数据通路。

## 非恢复开方

`nonrestoring` 变体维护部分根和有符号余数。每一步取被开方数的两位，把余数左移两位，并根据原余数符号选择加法或减法。新余数的符号决定下一根位。循环完全展开，`root_bits_per_stage` 决定每级组合 1、2 或 3 个根位步骤。

根位数取目标尾数字段宽度 `fb` 加 5，包括隐含整数位及四个额外小数位。全部根位生成后修正负余数，余数是否为零形成精确性信息。规格化和舍入级利用根位及 sticky 位完成五种舍入方式；完全平方数可以生成无 NX 的精确结果。

每个流水级使用独立的加减逻辑和寄存状态，不需要乘法器。根位选择与余数更新中的加减采用前缀加法器。

`root_lookahead=true` 时每级生成两位。设级入口的余数为 `R`、部分根为 `Q`、随后四个被开方位为 `P`，两步后的余数等于 `16R+P` 加上下表的修正项：

| 入口余数符号 | 第一步余数符号 | 修正项 |
|---|---|---|
| 非负 | 非负 | `−24Q−9` |
| 非负 | 负 | `−8Q−1` |
| 负 | 非负 | `8Q+7` |
| 负 | 负 | `24Q+15` |

硬件并行计算两种第一步符号假设下的结果，再由第一步实际余数符号选择。`8Q`、`16Q` 通过移位生成，多操作数加法经过压缩树和前缀加法器。第二步不再等待第一步的完整余数加减结果，代价是增加并行加法资源。

## 查表与乘法修正变体

`normalized_table` 覆盖所有有效数和指数奇偶情况，保存未舍入根位和余数非零标志。BF16 有 256 项，FP16 有 2,048 项。表后执行指数恢复与统一舍入。

`newton_residual` 用未舍入的倒平方根近似乘以输入有效数，形成平方根候选。`goldschmidt` 直接使用其平方根伴随量。两种结构均以完整的 `q²` 比较被开方数，按相邻平方差 `2q+1` 作固定校正，再生成精确性信息。候选距离精确截断根至多为 1 的条件通过规格化有效数与指数奇偶穷举检查。

默认结构和实际切分由[共同契约](../../src/zircon_asic/data/contract.json)读取，参数与表见 [`sfu.json`](../../src/zircon_asic/data/sfu.json)。面积、延迟与选型证据见[配置清单](../../reports/CONFIGURATIONS.md)。正确舍入的恢复／非恢复开方结构也见 [FloPoCo 算子说明](https://flopoco.org/operators_5.0.git.html)。

## 接口与特殊值

```python
from zircon_asic import FP16Sqrt, Request

unit = FP16Sqrt()
result = unit.compute(Request(a=0x4400))  # sqrt(4)
assert result.bits == 0x4000             # 2
assert result.flags == 0
```

输入只使用 `Request.a`；`b/c` 默认 0，仍检查位宽。`compute_batch(a)` 支持批量一元调用。输出沿用 `Response`，`remainder=0`，标签不变。

| 输入 | 结果 | 异常 |
|---|---|---|
| `+0`、`-0` | 保持输入零的符号 | 无 |
| `+Inf` | `+Inf` | 无 |
| 负有限非零数、`-Inf` | 规范化 quiet NaN | NV |
| quiet NaN | 规范化 quiet NaN | 无 |
| signaling NaN | 规范化 quiet NaN | NV |
| 正有限非零数 | 正确舍入结果 | 余数非零时 NX |

三种格式的正有限非零输入产生正规有限结果。Python 使用整数开方和精确中点比较；Numba 使用整数根位生成；RTL 使用契约选定的结构。数值参考独立使用 MPFR 有向上下界。

## 流水控制

每级容量为 1，启动间隔为 1。无背压时，第 `k` 拍接收的请求在第 `k+L` 拍交付；`describe()["latency"]` 返回 `L`。特殊值经过完整流水，不提前结束。

每级在自身空闲或下一级能够接收时推进。输出阻塞期间有效位、结果编码、异常、标签保持稳定。复位和 `flush` 抑制本拍握手并清除在途有效位。功能计算与批量计算不修改周期状态。
