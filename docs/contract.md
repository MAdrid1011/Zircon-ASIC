# 数值与周期契约

`src/zircon_asic/data/contract.json` 是 Python 包与 Chisel 共用的规范。`schema_version` 描述文件结构，`interface_version` 描述端口，`profile` 描述当前实现配置。哈希使用排序键、无空白 JSON 的 SHA-256；配置变化使旧验收记录失效。

## 请求与响应

`Request` 含原始位向量 `a/b/c`、三位 `rounding` 和 32 位无符号 `tag`。二元操作忽略 `c`。`Response` 含同位宽 `bits`、五位 `flags`、原样返回的 `tag` 和同位宽 `remainder`。非整数除法的余数字段为零。硬件使用 `Decoupled` 请求和响应，另有同步 `flush`。

Python 的 `b/c` 默认值均为 0，原位置参数顺序保持不变。一元算子只使用 `a`，`b/c` 仍检查字段位宽，不参与浮点分类。`compute_batch(a, b=0, c=0, ...)` 支持同样的一元调用。所有数值参数是原始整数位编码。

| 舍入码 | 名称 | 方向 |
|---|---|---|
| 0 | RNE | 最近，恰好中点取偶数 |
| 1 | RTZ | 向零 |
| 2 | RDN | 向负无穷 |
| 3 | RUP | 向正无穷 |
| 4 | RMM | 最近，恰好中点取较大绝对值 |

异常位从低到高为 `NX=1`、`UF=2`、`OF=4`、`DZ=8`、`NV=16`。整数加乘使用 `OF` 表示同位宽有符号或无符号结果溢出；不设置浮点不精确标志。

## 浮点编码

| 名称 | 符号/指数/尾数 | 偏置 | 非有限值 |
|---|---|---|---|
| fp32 | 1/8/23 | 127 | NaN、Inf |
| fp16 | 1/5/10 | 15 | NaN、Inf |
| bf16 | 1/8/7 | 127 | NaN、Inf |
| e4m3fn | 1/4/3 | 7 | 两个带符号 NaN 编码，无 Inf |
| e5m2 | 1/5/2 | 15 | NaN、Inf |
| e2m1 | 1/2/1 | 1 | 无 NaN、Inf |

浮点加、乘、FMA 和除法的目标格式与输入格式相同。FMA 对精确乘积与加数求和后仅舍入一次。次正规数不清零。binary32、binary16、bfloat16、E5M2 的 signaling NaN 设置 `NV`；输出分别规范化为 `0x7fc00000`、`0x7e00`、`0x7fc0`、`0x7e`。E4M3FN 的 NaN 规范化为 `0x7f`。

微小检测遵循 IEEE 的舍入后规则：先假定指数范围不受限，以目标有效数精度舍入，判断该结果是否小于最小正规数；之后仍将精确结果一次舍入到目标格式的次正规网格。微小且不精确才设置 `UF`。因此最终编码恰好是最小正规数时也可能同时报告 `UF|NX`。已保留 `FP16 0xaba0 * 0x1432` 的边界回归。[SoftFloat FAQ](https://www.jhauser.us/arithmetic/SoftFloat-3/doc/SoftFloat-FAQ.html)

IEEE 风格格式按舍入方向选择溢出到无穷或最大有限值，设置 `OF|NX`。E4M3FN、E2M1 则在**精确绝对值超过最大有限值**时饱和并设置 `OF|NX`；这一定义适用于五种舍入方式。E4M3FN 最大值为 448，E2M1 最大值为 6。标量算术规则是本库的明确约定，不能由存储格式名称单独推断。

非零有限值除以零设置 `DZ`，IEEE 风格格式返回带符号无穷，有限格式返回带符号最大值。E2M1 的 `0/0` 返回 `+0` 并设置 `NV`；其他格式返回规范 NaN 和 `NV`。E4M3FN 的 `0/0` 返回 `0x7f`。有符号零的乘除符号为操作数符号异或；加法或 FMA 精确抵消时按 `RDN` 返回负零，其他舍入方式返回正零。相同符号的零相加保留该符号。

## 一元浮点运算

FP32、FP16、BF16 支持 `exp`、`rcp`、`sqrt`、`rsqrt`。输入与输出采用相同格式，均保留次正规数。

| 运算 | 数值规则 | 舍入模式 |
|---|---|---|
| exp | 返回夹住数学真值的两个相邻数之一，误差严格小于其间距，单调不减 | RNE |
| rcp | 对 `1/x` 正确舍入 | 全部五种 |
| sqrt | 对 `sqrt(x)` 正确舍入 | 全部五种 |
| rsqrt | 对 `1/sqrt(x)` 直接正确舍入 | 全部五种 |

exp 在精确可表示时返回该值，零、正规／次正规交界和溢出类别使用独立生成的输入阈值判断。其最终定点结果按 RNE 打包。有限非零输入设置 NX；`exp(±0)=1`，无 NX。其近似误差相对于数学真值定义，三种执行后端之间仍逐位相同。

rcp 的零输入返回同符号 Inf 和 DZ，无穷输入返回同符号零。sqrt 保留零的符号，`sqrt(+Inf)=+Inf`。rsqrt 的零输入返回同符号 Inf 和 DZ，`rsqrt(+Inf)=+0`。sqrt／rsqrt 的负有限非零输入和 `-Inf` 返回规范化 quiet NaN、NV。四项运算均将 quiet NaN 规范化，signaling NaN 另外设置 NV。

`sfu.json` 随 Python 包与 Chisel JAR 分发，记录定点位宽、截断规则、表、系数、阈值和生成器摘要。共同契约记录每个算子的资源摘要、实现变体及实际流水切分。原理分别见 [exp](hardware/exp.md)、[rcp](hardware/rcp.md)、[sqrt](hardware/sqrt.md)、[rsqrt](hardware/rsqrt.md)。

## 整数

默认二进制补码有符号，也支持实例级无符号配置。加法、乘法使用完整中间值检查范围，输出低 `W` 位。除法向零截断；余数与被除数同号，满足无异常情况下的 `a = quotient*b + remainder`。

除零时商为全一、余数为原始被除数、标志为 `DZ`。有符号最小负数除以 `−1` 返回最小负数编码、零余数、`OF`。特殊输入不提前结束迭代。

## 周期推进

每拍先观察当前状态和本拍输入，计算 `valid/ready`，记录握手，再统一提交下一状态。`valid && ready` 是唯一传输条件。第 `k` 拍接收、延迟为 `L` 时，无背压输出在 `k+L` 拍交付。结果就绪定义为响应首次出现在输出端口；若 `out_ready=0`，交付时刻晚于就绪时刻。

弹性流水级容量均为一。末级推进条件为 `!valid[last] || out_ready`，其余级为 `!valid[i] || ready[i+1]`。推进的级从旧的上游状态接收有效位，仅在上游有效时更新数据。该规则允许空洞被填补，也允许一次握手后旧结果后移、新请求进入。启动间隔为一。

迭代除法器仅容纳一笔请求，依次执行契约给出的预处理、迭代和后处理阶段。完成后停留在响应阶段，直到交付。交付旧响应的同拍可以接收新请求，因此无背压启动间隔等于完整延迟。

复位和清空优先于传输，本拍 `in_ready` 与 `out_valid` 均被抑制，提交时清除在途状态。调试观察点仍反映提交前的旧状态；取消统计据此记录。数值数据寄存器不因清空而写零，其有效位决定数据是否有意义。

`Timing(..., matched=False)` 可显式创建架构探索模型。自定义时序在 `describe()` 中标记为 `exploration`，不继承硬件验收状态。
