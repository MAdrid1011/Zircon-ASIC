# 算术结构与测量

本版在 ASAP7 RVT、TC 0.70 V/0 °C 下，以 1000 ps 时钟、200 ps IO 预算、50 ps 不确定度验收。面积包含标签、流水寄存器、停顿和观察接口。仅在数值与周期验证通过、setup/hold 均非负且吞吐符合契约的候选之间比较面积×最坏无背压延迟；相差不足 5% 时优先较小面积。

## 测量驱动的选择

| 部件 | 候选及结果 | 采用结构 |
|---|---|---|
| FP32/FP16 加、乘、FMA | 初始短流水无法满足目标；拆开解码、算术、规格化、GRS 与舍入后收敛 | 加 6、乘 7、FMA 8 拍，均 II=1 |
| FP32 除法 | 初始 radix-16 每拍串联两个 radix-4 步，未达到 1 GHz | radix-4 SRT，13 次迭代，总计 19 拍；固定迭代，无特殊值提前结束 |
| FP32 FMA | 8 拍较大候选面积 1654.86 µm²；紧凑候选 1615.20 µm²，小 2.40%，两者均完成详细布线且通过时序 | 紧凑候选 `f3f82584bff6`，setup +13.21 ps、hold +1.20 ps；面积×延迟 12921.60 µm²·ns |
| FP16 FMA | 并行负幅值候选 800.952 µm²；串行绝对值候选 779.345 µm²，小 2.70%，同为 8 拍且通过时序 | 串行候选 `7e8046395258`，setup +17.16 ps、hold +2.35 ps；面积×延迟 6234.76 µm²·ns |
| FP4 乘法 | 通用浮点通路未满足时序；小整数双符号处理为 61.3526 µm²；直接幅值相乘为 44.2211 µm² | 独立符号异或与幅值乘法，1 拍，setup +117.34 ps |
| E4M3FN FMA | 5 拍串行规格化候选裕量 −54.23 ps；并行计算规格化截取位置，增加布局修复目标后 +2.37 ps | 并行截取位置，5 拍、II=1 |
| E5M2 FMA | 并行截取位置候选 −26.50 ps；原规格化结构配合布局修复目标后 +21.10 ps | 保留原规格化结构，5 拍、II=1 |
| INT16/32 除法 | 规格化与初始商选择合拍形成长路径 | 两者分拍；正负商分别累积，候选余数并行计算；总延迟 13/21 拍 |
| BF16 加法 | `single_path` 与 `near_far` 的 6 拍候选都完成详细布线；前者面积 409.625 µm²，后者 423.549 µm² | `single_path`，6 拍、II=1，setup +191.33 ps、hold +1.29 ps |
| BF16 乘法 | 4 拍直接 Dadda 为 292.912 µm²；4 拍 Booth-Dadda 为 300.858 µm² | 直接 Dadda，4 拍、II=1，setup +78.83 ps、hold +1.01 ps |
| BF16 FMA | `fused_compressor` 的 8 拍候选完成详细布线并通过时序 | 融合压缩树，8 拍、II=1，面积 673.596 µm²，setup +67.73 ps、hold +0.73 ps |
| BF16 除法 | 12 拍 radix-4 SRT 在详细布线后保持时间为 −1.50 ps；16 拍 radix-2 非恢复候选通过全部时序检查 | radix-2 非恢复，10 次迭代、16 拍、II=16，面积 350.532 µm²，setup +154.03 ps、hold +1.17 ps |

## 非线性算子

12 个 exp、rcp、sqrt、rsqrt 单元均以 II=1 实现，并在详细布线、提取 RC 后选择。选择规则是先满足数值、周期、setup、hold、时钟与路由检查，再最小化面积乘无背压延迟；相差不足 5% 时优先较小面积。

| 配置 | 采用结构 | L | 面积 µm² | setup / hold ps |
|---|---|---:|---:|---:|
| FP32 exp | 32 项幅值表、3 次定点多项式，30 位小数通路 | 17 | 2898.800 | +70.833 / +5.186 |
| FP32 rcp | 两位商选择的展开倒数，除法前瞻与树形前缀加法 | 20 | 2140.990 | +42.968 / +1.011 |
| FP32 sqrt | 两位根位的非恢复开方，前瞻余数选择 | 20 | 2165.230 | +54.543 / +0.775 |
| FP32 rsqrt | 64 项初值表、两轮空间展开 Newton 余量修正，树形精确校正 | 34 | 8263.710 | +38.366 / +0.710 |
| FP16 exp | 16 项幅值表、2 次定点多项式，17 位小数通路 | 10 | 996.178 | +34.120 / +1.181 |
| FP16 rcp / sqrt / rsqrt | 规格化有效数表与公共指数恢复、精确舍入 | 5 / 5 / 5 | 411.666 / 530.304 / 512.691 | +276.798 / +1.278；+237.141 / +0.681；+168.594 / +1.023 |
| BF16 exp | 16 项幅值表、2 次定点多项式，16 位小数通路 | 10 | 911.512 | +37.511 / +0.926 |
| BF16 rcp / sqrt / rsqrt | 规格化有效数表与公共指数恢复、精确舍入 | 5 / 5 / 5 | 290.404 / 300.581 / 309.898 | +183.088 / +1.120；+258.089 / +0.675；+181.964 / +1.347 |

FP32 exp 的系数、范围缩减、表量化和逐级截断以 Sollya 区间界筛选；其余三个 FP32 单元用完整整数余量确定最终五种舍入模式。FP16 与 BF16 的有效数规模适合表实现，表值保留未舍入信息，经过指数恢复和次正规移位后统一打包。完整的数值、周期、网表回放和 CPU 记录见 [非线性算子验证记录](SFU.md)。

FP32 FMA 的两项面积均来自详细布线；其他表内面积比较来自全局布线后的同级评估。具体源码哈希、候选测量、物理阶段和全部配置数据保存在 `validation.json`。FP32 除法最终详细布线为 setup +38.46 ps、hold +6.81 ps，面积 754.894 µm²。布局修复目标与时钟、IO、不确定度约束分别记录于配置文件。

其他算术模块采用：INT32 Brent–Kung、INT16 分组超前进位、INT8 普通进位加法；大整数和 FP32 使用 Booth/Dadda 乘法；小整数使用 Baugh–Wooley/Dadda；小浮点使用直接部分积；FP8/INT8 使用非恢复除法。

## 验收范围

既有 38 个配置各完成 12000 拍随机输入、背压、复位和清空回归；组合网络完成 20000 拍。宽浮点另使用 SoftFloat 和每种舍入方式 2048 项 TestFloat level-1 前缀；FP4/FP8 完成全部输入和五种舍入方式的 Numba、RTL 穷举。FP16/FP32 FMA 又以 Icarus 独立重放各 12000 拍。

BF16 四项分别完成五个 20,000 拍种子和一个 100,000 拍种子，数值回归覆盖五种舍入方式。四项均采用详细布线与提取 RC 证据。`dual-verified` 对应数值、逐周期和表中物理条件三项检查通过。
