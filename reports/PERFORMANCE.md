# CPU 模拟器实测

测试环境：Apple M3 Pro，macOS-26.7-arm64-arm-64bit，Python 3.12.7，NumPy 1.26.4。

每项批量包含 100000 个随机位编码，固定种子 737。下表使用预热后的 Numba，包含 API 参数处理与结果数组构造；首次调用可能编译或加载缓存。

| 算子 | Python 批量 / s | Numba 批量 / s | 加速倍数 |
|---|---:|---:|---:|
| fp32.fma | 0.610025 | 0.008503 | 71.74× |
| fp16.div | 0.514034 | 0.003013 | 170.59× |
| e4m3fn.mul | 0.552661 | 0.002518 | 219.52× |
| e2m1.fma | 0.247685 | 0.006478 | 38.24× |

16 个独立 INT8 乘法模块各运行 4100 拍：Python 0.384646 s，Numba 0.114053 s，提升 3.37×。计时包括状态打包和输出物化，关闭逐拍轨迹。

以上是 CPU 执行速度；硬件周期延迟、启动间隔和背压行为由共同契约及逐周期回归单独验证。完整原始时间记录位于 `validation.json` 的 `benchmark` 字段。

## BF16

BF16 批量测试使用 1,000,000 个随机位编码，固定种子 751。下表为五次预热后 Numba 运行的中位数，单位为秒。

| 算子 | Python 批量 / s | Numba 批量 / s | 加速倍数 |
|---|---:|---:|---:|
| bf16.add | 5.326773 | 0.076623 | 69.52× |
| bf16.mul | 5.040964 | 0.027491 | 183.37× |
| bf16.fma | 5.862149 | 0.081712 | 71.74× |
| bf16.div | 5.025299 | 0.027985 | 179.57× |

两条百万拍网络路径也在 Python 与 Numba 间逐拍核对：`add → mul → FMA` 从 32.101273 s 降至 1.888668 s，速度为 17.00×；`SPM → FMA → SPM` 从 43.537352 s 降至 2.329718 s，速度为 18.69×。
